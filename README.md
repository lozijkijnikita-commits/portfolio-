# Портфолио — Никита Лозицкий

Одностраничный сайт-портфолио: тёмная тема, крупная типографика, лаймовый акцент,
анимации при скролле и адаптив под телефон.

## Как открыть

Просто откройте `index.html` в браузере — сборка не нужна.

Для локального сервера (чтобы всё работало как на хостинге):

```powershell
cd C:\portfolio
python -m http.server 8080
```

Затем откройте http://localhost:8080

## Структура

```
portfolio/
├─ index.html      разметка и тексты
├─ styles.css      вся стилизация
├─ script.js       меню, появление блоков, свечение за курсором
└─ assets/
   ├─ lapki-hero.jpg   превью «Лапки и Хвосты»
   └─ apex.svg         превью APEX ONE (нарисовано в SVG)
```

## Что заменить

1. **Третий проект** — карточка №3 сейчас стоит как «свободный слот». Когда будет ссылка,
   замените блок `<!-- Проект 3 -->` в `index.html` на такую же карточку, как у проектов 1 и 2
   (превью + название + описание + теги + ссылка).
2. **Контакты** — Telegram уже стоит: `https://t.me/nikitosikmn` (карточка в секции `#contact`,
   кнопка в шапке, в hero и в подвале). Если юзер поменяется — замените `nikitosikmn` по всему
   `index.html`. E-mail можно добавить рядом кнопкой `mailto:...`.
3. **Тексты** — заголовки, описание и цифры в секции «Обо мне» правятся прямо в `index.html`.
4. **Превью проектов** — положите скриншоты в `assets/` и укажите их в `src` у `<img>`.
   Сейчас у «Лапок» стоит фото с сайта, у APEX ONE — нарисованная SVG-схема.

## Публикация

Вариант 1 — отдельный репозиторий на GitHub Pages:

1. Создайте репозиторий, например `portfolio`.
2. Загрузите туда **содержимое** папки `portfolio` (не саму папку).
3. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
4. Сайт появится на `https://<username>.github.io/portfolio/`.

Вариант 2 — любой статический хостинг (Netlify, Vercel, Cloudflare Pages):
достаточно перетащить папку `portfolio` в панель хостинга.

## Особенности

- Без фреймворков и сборки — только HTML, CSS и JS.
- Поддержка `prefers-reduced-motion`: анимации отключаются, если так настроена система.
- Мобильное меню, доступные фокусы, семантическая разметка.
